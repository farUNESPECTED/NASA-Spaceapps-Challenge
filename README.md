# Earth System Trend Detective
An automated data-driven framework designed to detect, track, and evaluate environmental anomalies using multi-mission Earth observation time-series. The platform ingests regional and global satellite data—focusing on surface, atmospheric, and vegetation indicators—to isolate true long-term ecological shifts from cyclical seasonal noise.
